## Getting Started

Simple Application ALarmClock.
Application Accepts user input for a specif time to trigger the alarm. Once the sytem has valid input it will trigger a sound to play when the specified alarm is reached. Alarm will play until user input to trigger the alarm to stop.

#### Features
- Threads
- User input
- File Reading
- Exception Handling
- DateTime handling
- Inheritance
- OOP

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies
- `src\assets`: the folder to maintain resources for the application (files, images..etc)

Meanwhile, the compiled output files will be generated in the `bin` folder by default.
